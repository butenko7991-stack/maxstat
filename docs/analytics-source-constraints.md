# Ограничения публичных источников аналитики

Проверено 4 октября 2026 года на публичных страницах источников, используемых в закупах.

| Источник | Публичный путь | Ограничение | Поведение приложения |
|---|---|---|---|
| PostXbot / Maxapp PostXbot | `/watchpost/{hash}` | HTML может быть стартовой оболочкой; структурированные данные доступны через публичный watch API | Использовать API отчёта и суммировать все размещения на 24-м часу |
| Marketly / Отложка Marketly | `/analytics/stats/{id}` | В некоторых старых отчётах отсутствует точная точка 24 часов в истории | Брать общий итог или восстанавливать точку только по двум соседним снимкам каждого размещения |
| Аналитика МАХ | `/ad/ad_{id}` | HTML — оболочка; данные в JSON API на том же хосте | Использовать публичный API, а не HTML |
| Обычная ссылка MAX | `max.ru/...` | Серверный запрос возвращает ограниченный доступ; публичной исторической точки 24 часа нет | Сообщить, что требуется ссылка отчёта аналитического бота |
| Трекеры на Amvera | `*.amvera.io/ad/...` | Публичный источник может вернуть HTTP 429 с `Retry-After` | Выполнять ссылки одного источника последовательно и выводить домен и срок повторной попытки |

Никогда не записывать частичную сумму по сетке: общий охват допустим только при явном общем показателе отчёта либо при наличии 24-часового значения у каждого размещения.
