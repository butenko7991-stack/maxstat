# Исследование ссылок go.аналитика-мах.рф

Проверенная ссылка: `https://go.аналитика-мах.рф/ad/ad_-70945865509462_1786471897531_5pup1v`.

## Наблюдения

- HTML-страница является клиентским шаблоном: в исходном HTML поле «За 24 часа» содержит заполнитель `...`, а не фактическое число.
- Фактические данные подгружаются браузером после открытия страницы через публичный запрос `GET /api/ad/{код}?hours=48` на том же хосте.
- Код рекламного размещения для приведённой ссылки: `ad_-70945865509462_1786471897531_5pup1v`.
- Страница отображает общий охват за 24 часа и разбивку по отдельным каналам, поэтому извлечение должно использовать API-ответ, а не общий AI-разбор HTML.
